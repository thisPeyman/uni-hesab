# حساب 🌿

**مدیریت مالی شخصی، ساده و محلی** — یک پروژه دانشگاهی با رابط فارسی، چیدمان راست‌به‌چپ، تاریخ شمسی و مبالغ به تومان.

## اجرا

پیش‌نیاز: Python 3.12 یا جدیدتر و [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run streamlit run app.py
```

در مرورگر آدرس **http://127.0.0.1:8501** را باز کنید. برای پایان اجرا در ترمینال `Ctrl+C` بزنید. هنگام اولین نصب اینترنت لازم است؛ پس از نصب، استفاده از برنامه و قلم فارسی نیاز به اینترنت ندارد.

اگر دسترسی شبکه محدود است و پراکسی SOCKS روی پورت 10808 دارید:

```bash
ALL_PROXY=socks5h://127.0.0.1:10808 HTTPS_PROXY=socks5h://127.0.0.1:10808 uv sync
```

## شروع سریع

1. برای حساب شخصی، تاریخ شروع شمسی و مجموع پول نقد/بانکی خود در همان روز را وارد کنید. مثال قالب تاریخ: `1405/08/09`.
2. درآمد و هزینه‌ها را با دکمه «ثبت تراکنش» اضافه کنید. مبلغ صحیح و به **تومان** است؛ ورودی با رقم فارسی یا انگلیسی پذیرفته می‌شود.
3. در «بودجه‌ها» برای دسته‌های هزینه سقف تعیین کنید.
4. در «هدف‌ها» یک هدف بسازید و از پول موجود به آن تخصیص دهید.
5. از «تنظیمات» خروجی CSV یا پشتیبان کامل بگیرید.

برای ارائه دانشگاهی، **حالت نمایشی** را در نوار کناری روشن کنید. این حالت داده ساختگی دارد و هیچ تغییری در داده شخصی ایجاد نمی‌کند. تغییرات نمایشی بین اجراها باقی می‌مانند.

## امکانات

- نمای کلی با موجودی کل، ذخیره هدف‌ها، پول قابل خرج، درآمد/هزینه ماه و نمودار دسته‌ها.
- ثبت، ویرایش، حذف تأییدشده، جست‌وجو و فیلتر تراکنش‌ها.
- دسته‌های پیش‌فرض فارسی، ساخت دسته، تغییر نام و بایگانی بدون حذف تاریخچه.
- بودجه ماهانه شمسی با قانون تکرارشونده، استثنای یک‌ماهه و حفظ سقف‌های تاریخی.
- هدف پس‌انداز با مهلت اختیاری، تخصیص/آزادسازی، تاریخچه و تکمیل/بایگانی.
- خروجی CSV سازگار با متن فارسی و پشتیبان کامل SQLite.
- ذخیره جداگانه داده شخصی و نمایشی.

## قواعد مهم

```text
موجودی کل = موجودی اولیه + درآمدها − هزینه‌ها
پول قابل خرج = موجودی کل − پول کنارگذاشته‌شده برای هدف‌ها
```

موجودی اولیه درآمد نیست. تخصیص به هدف هم هزینه نیست و موجودی کل را کم نمی‌کند. برای خرید واقعی باید هزینه جداگانه ثبت کنید. قبل از تکمیل یا بایگانی هدف، پول کنارگذاشته‌شده آن را آزاد کنید.

ثبت هزینه واقعی حتی اگر موجودی یا پوشش هدف‌ها را منفی کند مجاز است؛ برنامه هشدار می‌دهد و تخصیص‌ها را خودکار دست‌کاری نمی‌کند. تخصیص جدید بیش از پول قابل خرج یا مبلغ هدف مجاز نیست.

بودجه فقط هزینه‌های همان دسته و ماه شمسی را می‌شمارد. مانده بودجه به ماه بعد منتقل نمی‌شود. قانون جدید از ماه انتخاب‌شده اعمال می‌شود؛ استثنای ماهانه اولویت بالاتر دارد. **سقف صفر** با «بودجه تنظیم نشده» متفاوت است.

تراکنش باید بین تاریخ شروع حساب و امروز باشد. زمان امروز بر اساس `Asia/Tehran` محاسبه می‌شود. ثبت آینده و تکرار خودکار جزو این نسخه نیست.

## محل داده و حریم خصوصی

```text
data/personal.sqlite3    داده واقعی شما
data/demo.sqlite3        داده نمایشی مستقل
```

این پوشه در Git قرار نمی‌گیرد. می‌توانید با متغیر محیطی `HESAB_DATA_DIR` مسیر دیگری انتخاب کنید. برنامه روی `127.0.0.1` اجرا می‌شود؛ اتصال بانک، ارسال آمار استفاده یا بارگذاری قلم از CDN ندارد.

**داده و فایل پشتیبان رمزگذاری نشده‌اند.** هرکس به فایل‌ها دسترسی داشته باشد، می‌تواند اطلاعات را بخواند. برنامه بدون احراز هویت برای استفاده محلی طراحی شده؛ آن را با داده واقعی روی شبکه عمومی منتشر نکنید.

### بازیابی دستی پشتیبان

بازیابی از داخل رابط در این نسخه وجود ندارد:

1. همه اجرای‌های برنامه را کاملاً متوقف کنید.
2. از فایل فعلی `data/personal.sqlite3` یک کپی ایمن تهیه کنید.
3. فقط یک پشتیبان مورد اعتمادِ ساخته‌شده با همین نسخه برنامه را به جای آن کپی کنید و نامش را `personal.sqlite3` بگذارید.
4. برنامه را اجرا و موجودی/تراکنش‌ها را بررسی کنید؛ در صورت مشکل، پس از توقف برنامه کپی قبلی را برگردانید.

CSV فقط شامل تراکنش‌هاست، نه بودجه و هدف‌ها؛ برای حفظ کل حساب از پشتیبان SQLite استفاده کنید. CSV ورودی در این نسخه پشتیبانی نمی‌شود.

## آزمون و کنترل کیفیت

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run ty check hesab app.py
```

بررسی اختیاری در Chrome، پس از اجرای برنامه (فقط با داده نمایشی؛ تراکنش آزمایشی خود را حذف می‌کند):

```bash
uv run --with playwright python tests/browser_smoke.py
uv run --with playwright python tests/browser_layout.py
uv run --with playwright python tests/browser_sidebar.py
```

این اسکریپت به Google Chrome در `/usr/bin/google-chrome` نیاز دارد و تصویرها را در `/tmp/opencode/hesab-screenshots` ذخیره می‌کند. مسیر مرورگر را در صورت نیاز متناسب با سیستم خود تغییر دهید.

آزمون `browser_layout.py` بدون ذخیره داده، هم‌پوشانی راهنمای ورودی، ثبات جای دکمه ثبت، نمایش کامل گزینه‌ها و نشان‌ها و پنهان‌شدن نوار کناری را در عرض‌های `1366`، `768` و `390` پیکسل بررسی می‌کند. تصویرهای آن در `/tmp/opencode/hesab-layout` ذخیره می‌شوند.

تست‌ها شامل مبالغ صحیح، مرز ماه شمسی و اسفند کبیسه، ثبت/ویرایش/حذف تراکنش، تاریخچه بودجه، هدف‌ها، کسری موجودی، تخصیص هم‌زمان، جداسازی حالت نمایشی، CSV و سلامت پشتیبان هستند. آزمون‌های رابط با `AppTest` خود Streamlit اجرا می‌شوند. بررسی اندازه صفحه و ظاهر واقعی با مرورگر در کنار آزمون خودکار انجام می‌شود.
